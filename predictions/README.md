## A01

**到 2027-04-30，METR 在 Time Horizon 1.1 公布至少一个可供外部用户使用的模型，其 50% 任务完成时距点估计达到 24 小时。**

基准为当前页面列出的 Claude Mythos Preview（early）约 **17 小时**。时距指人类专家完成任务的估算时长。推理、工具使用和长程规划在改善，限制是长任务样本有限、评估常滞后，且外部可用要求可能晚于研究试用。 [METR 基准与方法](https://metr.org/time-horizons/)。

**判定。** 读取 METR 的 1.1 仪表板、数据下载或明确采用 1.1 的独立报告。须有模型一般可购买或公开可用记录。仅内部、邀请或安全研究环境不算，不能用 1.0 或后续不同任务集替代。截止前没有合格公开记录即 NO。若 METR 撤下固定任务集且后续无法读取发布记录，记 VOID 并说明。此结果只代表这一类软件任务。

## A02

**到 2027-06-30，Statesville 与 Lebanon 两处 GXO 场地均在实际履约业务中使用过 Agility Digit。**

Flowery Branch 是公开的使用基准。扩张有既有客户与明确场地，也面临施工、验收、整合和班次安排风险。预计年初上线的 Digit 4 已可计入；Digit 5 的 GA 只是线索。 [GXO 客户公告](https://gxo.com/news_article/gxo-and-agility-robotics-expand-partnership-to-accelerate-deployment-of-humanoids-in-u-s-operations/)。

**判定。** GXO 运营资料或监管文件要分别确认两个场地、上线时间和已处理的实际业务任务，例如搬运实际订单对应的周转箱。仅设备运抵、测试、意向、付费承诺或泛称「计划部署」不算。只有一处或者无合格披露为 NO。

## A06

**到 2029-11-25，NCT07687459 首次公开随机对照三期的主要有效性结果，且达到预先说明的统计优效标准。**

登记预计 **2029-10-30** 主要完成，计划 320 人。已有三期执行，入组、失访、疗效与结果发布时间是四个约束。 [试验登记与研究历史](https://clinicaltrials.gov/study/NCT07687459)。

**判定。** 登记结果、论文、监管材料或带可核查统计表的结果公告须报告试验号、事先设定的主要有效性终点、组间估计与显著性判据。无优效、仅探索性亚组、无数值的积极措辞、因延期或其他原因未公布均为 NO。研究更名时仅接受登记管理员确认的同一 NCT。判定不等于批准。

## A07

**到 2028-11-25，ER-100 就青光眼或 NAION 启动一个前瞻注册、随机、有对照并预先指定至少一项视觉功能终点的后续人体研究。**

**判定。** 使用 ClinicalTrials.gov 或 WHO ICTRP 认可的注册记录，需有正式实际入组起始日、明确随机和对照及可读的人体视觉功能终点。只扩大现有开放标签队列、动物研究、登记意向或生物标志物终点为 NO。查不到合格研究亦为 NO。
